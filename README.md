# YodEdit: เว็บตัดต่อวิดีโออัตโนมัติ

อัปโหลดวิดีโอ แล้วระบบจะตัดช่วงเงียบ ใส่ซับภาษาไทยแบบเด้งทีละคำ ซูมตามจังหวะ
ใส่เสียงเอฟเฟกต์ และแปลงขนาดเป็น 9:16 / 16:9 / 1:1 / 4:5 ให้อัตโนมัติ

## สรุปฟีเจอร์ทั้งหมด

✅ = มีในดราฟแรกนี้ · ⏳ = เวอร์ชันถัดไป

### ตัดต่อเนื้อหา
- ✅ ตัดช่วงเงียบหรือหยุดพูด (ปรับระดับ dB และความยาวช่วงเงียบได้)
- ✅ ตัดคำฟุ่มเฟือย "เอ่อ อ่า อืม"
- ✅ ย่อคลิปให้พอดีความยาวที่ต้องการ (ตอนนี้เลือกช่วงที่พูดหนาแน่นที่สุด)
- ⏳ ให้ AI (Claude) อ่านเนื้อหาแล้วเลือกช่วงสำคัญจริง ๆ
- ⏳ หา Hook 3 วินาทีแรก และแบ่งคลิปยาวเป็นหลายคลิปสั้น
- ⏳ ตัดประโยคที่พูดซ้ำหรือพูดผิดแล้วพูดใหม่
- ⏳ สร้างชื่อคลิป แคปชัน แฮชแท็ก Thumbnail และ Chapter

### ซับไตเติล
- ✅ ถอดเสียงไทยอัตโนมัติ (Whisper) พร้อมเวลาระดับคำ
- ✅ ตัดคำไทยให้ถูกต้องด้วย PyThaiNLP
- ✅ ซับขึ้นทีละวลีสั้น ไฮไลต์คำที่กำลังพูด และเด้งเล็กน้อยตอนขึ้น
- ✅ ขนาดและตำแหน่งซับปรับตามสัดส่วนจอ (แนวตั้งวางค่อนกลางจอ หลบปุ่มของ TikTok)
- ✅ Export ไฟล์ .srt แยกสำหรับอัปโหลด YouTube
- ⏳ เลือกสไตล์ซับได้หลายแบบ และแก้ข้อความซับได้

### ภาพและจังหวะ
- ✅ ซูมเข้า-ออกสลับกันทุก ๆ X วินาที (jump zoom)
- ⏳ ซูมตามจังหวะเน้นเสียง หรือตอนพูดคำสำคัญ
- ⏳ B-roll อัตโนมัติจาก Pexels/Pixabay ตาม keyword
- ⏳ Emoji หรือไอคอนเด้งตามคำพูด, Progress bar, ปรับสีอัตโนมัติ

### ขนาดวิดีโอ
- ✅ เลือกได้หลายขนาดพร้อมกัน: 9:16, 16:9, 1:1, 4:5
- ✅ โหมดครอปกลางภาพ และโหมดภาพเต็มกับพื้นหลังเบลอ
- ⏳ Auto Reframe ให้กรอบตามหน้าคนพูด (MediaPipe)
- ⏳ แสดงเส้น Safe zone ของแต่ละแพลตฟอร์ม

### เสียง
- ✅ เสียง Whoosh ตอนตัดช็อต (สังเคราะห์เอง ไม่ติดลิขสิทธิ์)
- ✅ ปรับระดับเสียงมาตรฐาน -14 LUFS
- ⏳ SFX เพิ่ม เช่น pop และ ding, เพลงประกอบพร้อม Auto ducking, ลด noise

### ระบบ
- ✅ หน้าเว็บอัปโหลด, ระบบคิว และแถบแสดงความคืบหน้า
- ✅ Preview และดาวน์โหลดผลลัพธ์
- ✅ เก็บ timeline เป็นข้อมูลกลาง (`plan.json`) พร้อมต่อยอดเป็น editor
- ⏳ Editor ให้แก้ผลของ AI และแก้วิดีโอผ่านข้อความ (ลบคำ = ตัดวิดีโอ)
- ⏳ Template, Brand Kit, ระบบสมาชิกและเครดิต, ลบไฟล์อัตโนมัติ

## วิธีรัน (Windows)

ต้องมี Python 3.10 ขึ้นไป แล้วดับเบิลคลิก `run.bat`
- ครั้งแรกจะติดตั้งแพ็กเกจให้เอง
- ตอนถอดเสียงครั้งแรก faster-whisper จะดาวน์โหลดโมเดล (small ประมาณ 500 MB)

หรือรันเอง:

```
pip install -r requirements.txt
python -m uvicorn server:app --port 8000
```

แล้วเปิด http://localhost:8000

ใช้ผ่าน command line ก็ได้:

```
python -m autocut clip.mp4 --aspect 9:16 16:9 --target 60
```

## ขึ้นเซิร์ฟเวอร์ (Deploy)

> ⚠️ ใช้กับ Vercel / Netlify ไม่ได้ เพราะเป็น Serverless: อัปโหลดได้ไม่เกิน 4.5 MB,
> รันได้ไม่กี่นาที และขนาดแพ็กเกจเกิน 500 MB ต้องใช้บริการที่รัน Docker ค้างไว้ได้

`Dockerfile` เตรียมทุกอย่างให้ครบ (โมเดลภาษาไทย + ฟอนต์ Kanit) ใช้ได้กับ:

- **Hugging Face Spaces (ฟรี):** สร้าง Space แบบ Docker แล้วอัปโหลดไฟล์ใน repo นี้
  (ส่วนหัว README นี้คือค่าตั้งค่าของ Space) ครั้งแรกจะ build ประมาณ 10–20 นาที
- **Render / Railway / Fly.io:** เลือก Deploy จาก Dockerfile, ตั้งค่า port ผ่านตัวแปร `PORT`
- **VPS:** `docker build -t yodedit . && docker run -p 7860:7860 yodedit`

ตัวแปรที่ปรับได้: `KEEP_HOURS` (ลบไฟล์เก่าหลังกี่ชั่วโมง, ค่าเริ่มต้น 6),
`MAX_UPLOAD_MB` (ขนาดไฟล์สูงสุด, ค่าเริ่มต้น 500), `AUTOCUT_DEVICE=cuda` (ถ้ามี GPU)

### โมเดลถอดเสียงภาษาไทย
Whisper ปกติถอดภาษาไทยผิดเยอะ (มีภาษาอื่นปนออกมา) โปรแกรมจึงใช้ **Thonburian Whisper**
(biodatlab, ม.มหิดล) ที่ฝึกมาเพื่อภาษาไทยโดยเฉพาะ ถ้ายังไม่มีโฟลเดอร์ `models/whisper-th-distill-large-v3`
ให้รัน `setup_thai_model.bat` ครั้งเดียว (ถ้าไม่มี โปรแกรมจะใช้ large-v3-turbo แทน)

### เคล็ดลับ
- ถ้ามีการ์ดจอ NVIDIA ให้ตั้ง `set AUTOCUT_DEVICE=cuda` ถอดเสียงจะเร็วขึ้นมาก
- อยากได้ฟอนต์สวยกว่านี้ ให้วางไฟล์ `.ttf` (เช่น Kanit หรือ Prompt จาก Google Fonts) ในโฟลเดอร์ `fonts/` แล้วเปลี่ยนชื่อฟอนต์ใน `Options.font`

autocut/render.py      ปรับสัดส่วนจอ, ซูม, ต่อคลิป, เบิร์นซับ
